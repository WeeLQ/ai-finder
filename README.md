# AI Finder — первая версия

## Запуск на компьютере
Откройте `index.html` в браузере. Никакие установки не нужны.

## Публикация через GitHub Pages
1. Создайте на GitHub новый публичный репозиторий, например `ai-finder`.
2. Загрузите в него файл `index.html` (кнопка Add file → Upload files).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите Branch: `main`, Folder: `/ (root)`, нажмите Save.
6. Через некоторое время GitHub покажет адрес опубликованного сайта.

## Что уже работает
- адаптивная главная страница;
- каталог из 18 инструментов;
- поиск по названию, описанию и назначению;
- категории и фильтры;
- избранное в браузере пользователя;
- переходы на официальные сайты.

## Важно
Это стартовый MVP без сервера и аккаунтов. Избранное хранится локально в браузере.
Статусы бесплатного доступа ориентировочные: перед публикацией проверьте актуальные условия и доступность каждого сервиса в нужных странах.
